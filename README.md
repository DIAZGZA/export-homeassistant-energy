# Home Assistant Energy Export

Este repositorio contiene el código Python de exportación de energía y el add-on de Home Assistant Supervisor en `energy_export/`.

## Add-on

Añade este repositorio a **Ajustes → Complementos → Tienda de complementos → ⋮ → Repositorios** e instala **Energy Export**. El paquete completo, incluyendo Dockerfile, dependencias Python y scripts, vive en [`energy_export/`](energy_export/). La guía de instalación y configuración está en [`energy_export/README.md`](energy_export/README.md).
