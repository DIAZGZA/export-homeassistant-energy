# Home Assistant Energy Export

Este repositorio contiene el código Python de exportación de energía y el add-on de Home Assistant Supervisor en `energy_export/`.

## Add-on

Añade este repositorio a **Ajustes → Complementos → Tienda de complementos → ⋮ → Repositorios** e instala **Energy Export**. El add-on incluye la interfaz Ingress de selección sugerida de sensores. La guía completa está en [`energy_export/README.md`](energy_export/README.md).
